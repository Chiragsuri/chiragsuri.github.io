## Case Studies

### 1. [Retail Revenue & Anomaly Detection](https://chiragsuri.github.io/projects/sales-health-monitor/)
I built an automated BI pipeline to process over 800,000 retail transactions. False alerts are a massive drain on time, so I engineered a MySQL star schema and an adaptive anomaly detection layer in Python that cut them by 85%. The final output is a set of four Power BI dashboards driven by custom DAX.
* **Tech Stack:** MySQL, Python, Power BI, DAX

### 2. [Performance Forecasting Model](https://chiragsuri.github.io/projects/ipl-analysis/)
I wanted to see what actually drives cricket match outcomes instead of relying on gut feeling, so I extracted and structured data across 145 IPL datasets using SQL. I ran the exploratory analysis with Pandas to find player patterns, then wired it all into a Power BI dashboard. Coaches and analysts can filter through dynamic KPIs to see match flow and team performance.
* **Tech Stack:** SQL, Python (Pandas, Seaborn), Power BI

### 3. [Football Striker Segmentation](https://chiragsuri.github.io/projects/football-striker/)
This project answers a specific question: what separates an average striker from an elite one? I pulled data on 500 professional footballers, cleaned the raw stats, and used K-Means clustering to segment the players. I built a classification model to weigh the features. It turns out the underlying metrics tell a very different story than basic goal counts.
* **Tech Stack:** Python, Scikit-learn, K-Means Clustering

### 4. [Year-Over-Year Sales Analytics](https://chiragsuri.github.io/projects/sales-data-analysis/)
I needed a robust dataset to test year-over-year comparison models, so I generated synthetic sales data using Python's Faker and NumPy libraries. I cleaned the outputs to mirror realistic customer purchasing habits and piped it into Power BI. The dashboard tracks growth trends and maps out city-level performance.
* **Tech Stack:** Python (Pandas, Faker), Power BI

### 5. [Geospatial Real Estate Valuation](https://chiragsuri.github.io/projects/house-sales-analysis/)
I took a messy set of King County housing records and turned it into an interactive Tableau map. It allows real estate stakeholders to filter valuations by condition, build year, and location demographics. It is a straightforward, visual tool for finding pricing trends without looking at a single spreadsheet.
* **Tech Stack:** Excel, Tableau
