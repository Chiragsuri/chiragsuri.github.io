## 🚀 Featured Case Studies

### 1. [Sales Health Monitor – Automated BI Pipeline](https://chiragsuri.github.io/projects/sales-health-monitor/)
> **Goal:** Track YoY growth and isolate high-value customer segments without waiting for manual reports.

I built an automated BI pipeline that processes over 800,000 retail transactions. I engineered a MySQL star schema from scratch with 8 tables and 11 views. False alerts are a massive drain on time, so I wrote an adaptive anomaly detection layer in Python that cut them by 85%. The final output is a set of four Power BI dashboards driven by custom DAX.
* **Tech Stack:** MySQL, Python, Power BI, DAX

### 2. [IPL Data Analysis (Season 2024 and 2025)](https://chiragsuri.github.io/projects/ipl-analysis/)
> **Goal:** Uncover what actually drives cricket match outcomes and team performance.

I extracted and structured data across two IPL seasons using SQL. I ran the exploratory analysis with Pandas and Seaborn to find player patterns, then wired it all into a Power BI dashboard. Coaches and analysts can filter through dynamic KPIs to see match flow and team performance.
* **Tech Stack:** SQL, Python (Pandas, Seaborn), Power BI

### 3. [Football Striker Performance Analysis](https://chiragsuri.github.io/projects/football-striker/)
> **Goal:** Identify the underlying metrics that separate an average striker from an elite one.

I pulled data on 500 professional footballers and ran it through Scikit-learn. After cleaning and encoding the raw stats, I used K-Means clustering to segment the players and built a logistic regression model to weigh the features. It turns out the underlying metrics tell a very different story than basic goal counts.
* **Tech Stack:** Python, Scikit-learn, K-Means Clustering

### 4. [Geospatial House Sales Analysis](https://chiragsuri.github.io/projects/house-sales-analysis/)
> **Goal:** Create a visual tool for finding pricing trends without looking at a single spreadsheet.

I took a messy set of King County housing records and turned it into an interactive Tableau map. It allows real estate stakeholders to filter valuations by condition, build year, and location demographics. 
* **Tech Stack:** Excel, Tableau
